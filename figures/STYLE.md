# Figure style: Tick-Driven Renko series

Every figure is generated by a script in `figures/make_epNN.py`. There are no
hand-edited images. MQL5 article constraints: PNG, **exactly 750 px wide**, height
as needed (300–520 px typical), file size under 300 KB. English text only.

## Look
- matplotlib, `dpi=150`, `figsize=(5.0, h)` inches → 750 px wide.
- Font: DejaVu Sans. Title 11 pt semibold, labels 9 pt, ticks 8 pt, annotations 8 pt.
- White background, no top/right spines, light grid `#E6E8EB` on the value axis only.
- Colours (use only these):
  - up brick / buy: `#1F8A5B` (fill), edge `#14684A`
  - down brick / sell: `#C8423B` (fill), edge `#9E2F2A`
  - phantom brick (burst_index > 0): same hue at 35 % alpha with a dashed edge
  - forming / pending: `#9AA3AE`, dashed
  - price / tick path: `#2B4C7E`
  - reference line (baseline, level): `#6B7280` dashed
  - highlight / callout: `#D98E04`
  - neutral fill: `#EEF1F4`
- Every chart says what it shows in its title as a finding, e.g. "Naive fills overstate
  flip-follow by $X per trade". Generic titles like "Brick size vs cost" are not allowed.
- Units in axis labels ("Brick size ($ per oz)", "Cost per trade ($ per oz)").
- Any figure built from tester or historical data has a small grey source line at the
  bottom left: "XAUUSD ticks 2017-10 to 2026-09, Python port of RenkoSweep" or similar.
- Save with `bbox_inches=None` so the width stays at exactly 750 px.

## Covers and icons (one per article)
- Cover: 1200×628 PNG. Dark slate `#1E2A38` background, a row of up/down bricks in
  the series colours along the bottom third, series name small ("Tick-Driven Renko in
  MQL5") and the part title large in white. No logos and no money imagery.
- Icon: 60×60 PNG. Three bricks stepping up (green, green, red), flat, no text.
